# Can You Put Roofing Shingles in a Dumpster?

Yes, roofing shingles and tile are standard dumpster material, and a roof tear-off is one of the most common dumpster jobs. The catch is weight: roofing is heavy, and tile is much heavier than shingle, so the right box depends on what is coming off the roof. This post covers how to dumpster roofing debris, the big difference between shingle and tile, and sizing a re-roof load.

## Yes, Roofing Goes In

Asphalt shingles, underlayment, and the nails and flashing that come off with them are all standard roll-off debris. A dedicated roofing dumpster for a tear-off is routine, and keeping the load clean (just roofing material) helps with both weight management and recycling. See the [roofing dumpster page](/roofing-dumpster-rental/).

## Shingle vs Tile: The Weight Difference

This is the key distinction in Southwest Florida, where both roof types are common. Asphalt shingle is heavy, but concrete and clay tile are far heavier, roughly several times the weight per square. That changes the box:

- **Shingle tear-off:** a 20-yard box is the usual choice, with the weight allowance set for roofing.
- **Tile tear-off:** a 10-yard box filled partway, because tile hits the weight limit fast. A 20-yard box full of tile would be far too heavy for the truck.

Always tell the hauler whether the roof is shingle or tile when you book, since it changes the box and the weight allowance completely.

## Sizing a Re-Roof Load

Roofing is measured in squares (100 square feet each). The number of squares, plus the roof type, tells the hauler the weight to expect. A typical single-family shingle re-roof fits a 20-yard box; a larger home or a steep multi-layer tear-off may need more. For tile, the weight ceiling is reached sooner, so even a modest tile roof may need a 10-yard filled partway or more than one haul. Give the hauler the rough square footage and roof type for an accurate box and allowance.

## Frequently Asked Questions

**Can I put roofing shingles in a rental dumpster?**
Yes. Asphalt shingles, underlayment, nails and flashing are all standard roll-off debris, and a dedicated roofing dumpster for a tear-off is routine. Keeping the load clean, just roofing material, helps with weight management and recycling. The main thing to plan is weight, since roofing is heavy. A typical shingle re-roof fits a 20-yard box with the weight allowance set for roofing. Tell the hauler the roof type and rough size when you book so the box and allowance fit.

**What size dumpster do I need for a roof?**
It depends on the roof type and size. A single-family asphalt shingle tear-off usually fits a 20-yard box, with the weight allowance set for roofing. A tile roof is different: concrete and clay tile are several times heavier than shingle, so a tile tear-off goes in a 10-yard box filled partway, since a larger box of tile would exceed what the truck can lift. Give the hauler the rough square footage and the roof type for an accurate recommendation.

**Why does tile roofing need a smaller dumpster?**
Because concrete and clay tile weigh far more than asphalt shingle, roughly several times per square. A dumpster has a weight limit as well as a volume limit, and with tile the weight limit is reached long before the box is full. So a tile tear-off goes in a small box, usually a 10-yard, filled only partway, to stay within the truck's safe lifting capacity and your weight allowance. A 20-yard box full of tile would be far too heavy to haul safely.

**Can I mix roofing debris with other renovation debris?**
It is best to keep roofing in its own load. Roofing is heavy, so mixing it with general renovation debris can push the combined load overweight, and a clean roofing load recycles and prices better. For a re-roof, use a dedicated roofing dumpster sized for the roof type and square footage, and put any other project debris in a separate box. Tell the hauler the roof type (shingle or tile), since it sets the box size and weight allowance.
