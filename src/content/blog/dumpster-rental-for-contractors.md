# Dumpster Rental for Contractors

Contractors rely on roll-offs to keep job sites clear. This post covers contractor dumpster rental.

## Contractor Dumpster Rental

For a contractor, a roll-off is the job-site disposal point:

- **Size to the project and pace,** with swaps for a long job.
- **Separate heavy material** (concrete, masonry) into a small box.
- **Keep the site clear** so crews deposit debris rather than stockpiling.
- **Mind Lee County's C and D recycling** requirement.
- **Coordinate across sites** if you run multiple jobs, a hauler can schedule boxes and swaps.

Describe the project to the hauler, who sizes the box and plans swaps. See the contractor checklist for the full workflow.
