# What Size Dumpster for a Roof Tear-Off

Sizing a roof tear-off dumpster comes down to the roof type and the square footage. This post covers how to size it.

## Sizing the Tear-Off

Size a roof tear-off by two factors:

- **Roof type.** Shingle goes in a 20-yard box; tile in a 10-yard filled partway (tile is several times heavier).
- **Square footage.** Roofing is measured in squares (100 sq ft). A typical single-family shingle roof fits a 20-yard; a larger home or a steep multi-layer tear-off may need more. For tile, even a modest roof may need a 10-yard filled partway or more than one haul, since the weight ceiling comes sooner.

Give the hauler the roof type and rough square footage, and whether there are multiple old layers to remove (which adds weight and volume). They set the box and weight allowance. Keep the load clean of non-roofing debris. See the [roofing dumpster page](/roofing-dumpster-rental/).
