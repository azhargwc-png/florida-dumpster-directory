# Dumpster for Yard Waste in Florida

For routine yard waste, county curbside collection usually suffices; for a big job, a dumpster is the tool. This post covers the line, including Sarasota's Leaf It Out rule.

## Curbside vs Dumpster

Florida counties collect routine yard waste curbside, within limits:

- **Routine yard waste** (regular trimmings, bagged or bundled within size limits) goes curbside. Note Sarasota County's Leaf It Out rule bans plastic bags, requiring reusable containers or paper bags.
- **A large tear-out** (a big tree removal, a landscaping overhaul, storm vegetation) exceeds curbside limits, so a dumpster is the practical tool.

So use curbside for ongoing yard maintenance and a dumpster for a one-time big job. Yard-waste debris is bulky, so size a dumpster by volume (15- or 20-yard), unless there is heavy sod or soil, which goes in a small box. Describe the job to the hauler.
