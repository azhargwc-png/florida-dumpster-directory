# Shingle vs Tile Roof Dumpster Needs

The single biggest factor in a roofing dumpster is whether the roof is shingle or tile, because tile is far heavier. This post compares the two.

## Shingle vs Tile

**Shingle roofs** (asphalt) are moderately heavy. A tear-off fits a 20-yard box, and you can use much of its volume before hitting the weight allowance, since shingle is lighter than tile.

**Tile roofs** (concrete or clay) are several times heavier per square. A tear-off goes in a 10-yard box filled only partway, because the weight limit is reached long before the box fills. A 20-yard box of tile would be far too heavy to lift safely.

So the same roof area needs very different boxes depending on type: a 20-yard for shingle, a small box filled partway for tile. Always tell the hauler the roof type, since it changes the box size and weight allowance completely. Give the rough square footage too.
