# What Happens If You Need the Dumpster Longer

Projects run long, and extending a dumpster rental is simple if you arrange it ahead. This post covers needing the box longer.

## Needing More Time

If your project runs past the included rental period:

- **Call before the period ends** and ask to extend. Each extra day adds a daily rate.
- **Do not just hold the box** past the period without arranging it, which can lead to additional charges.
- **Consider a swap** if the box is also full, collecting the full box and dropping an empty one gives you more capacity and more time at once.
- **Plan ahead** for a known long project, with a longer period or a weekly rate.

Extending is routine; the key is to arrange it before the period ends rather than after. Confirm the daily rate when you book so an extension is predictable. Describe a long project to the hauler up front for the best rental structure.
