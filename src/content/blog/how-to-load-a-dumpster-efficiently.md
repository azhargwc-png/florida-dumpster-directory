# How to Load a Dumpster Efficiently

Loading a dumpster well can fit far more in the same box. This post covers efficient loading.

## Loading for Maximum Space

To use a box's full capacity:

- **Load big flat items first** (mattresses, plywood, doors, flattened furniture) along the bottom.
- **Break down bulky items** (shelving, furniture, cabinets, boxes) so they pack flat rather than trapping air.
- **Fill gaps** around large items with smaller debris and bags.
- **Distribute weight evenly** across the floor for safe lifting.
- **Work from the back (closed end) to the door** if the box has a door, so you can walk items in.
- **Keep it level with the fill line,** not heaped above.
- **Keep heavy debris in a small box filled partway** separately, rather than mixing it in.

Efficient loading fits more light debris in the same box, which can save you from a larger box or a second haul. It is mostly about breaking items down and filling gaps.
