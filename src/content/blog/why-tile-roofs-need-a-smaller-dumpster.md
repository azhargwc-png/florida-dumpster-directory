# Why Tile Roofs Need a Smaller Dumpster

It seems backward that a heavier roof uses a smaller box, but it is all about weight. This post explains why tile roofs go in a small dumpster.

## Heavier Means Smaller Box

A dumpster has a weight limit as well as a volume limit, and concrete or clay tile is so heavy, several times the weight of shingle per square, that a box of tile reaches the weight limit long before it fills by volume. So:

- **A 20-yard box of tile** would be far too heavy for the truck to lift safely and would blow past the weight allowance.
- **A 10-yard box filled partway** keeps the tile within the truck's safe lifting capacity and the weight allowance.

So the heavier material uses the smaller box, filled only partway, precisely because it is heavy. It is the same reason concrete goes in a small box. The small box is not about volume, it is about keeping the heavy load liftable and within the allowance. Tell the hauler it is a tile roof so they provide the right box.
