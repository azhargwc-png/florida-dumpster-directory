# Can You Extend a Dumpster Rental?

Yes, you can extend a dumpster rental, and it is a routine request, as long as you arrange it before the period ends. This post covers how extensions work.

## How Extensions Work

Most rentals include a set number of days, and if you need the box longer, you call the company to extend before the included period ends. Each extra day is billed at a daily rate. Extending is routine and simple; the key is to do it ahead of time rather than just holding the box past the period, which can lead to additional charges. If your project is running long:

- **Call before the period ends** and ask to extend.
- **Confirm the daily rate** for the extra days.
- **Consider a swap** instead, if the box is also full, so you get an empty box and more time at once.

If you instead finish early, call for pickup, which can free your driveway sooner, though it does not usually reduce the base rental.
