# Dumpster for a Construction Project

A construction project generates a steady flow of mixed debris, and a dumpster (or scheduled swaps) keeps the site clear. This post covers sizing and managing construction debris.

## Managing Construction Debris

Construction debris is a mix of wood, drywall, packaging, offcuts, and sometimes concrete and masonry. To handle it:

- **Size to the project and pace.** A moderate job fits a 20-yard; a larger build a 30- or 40-yard, or scheduled swaps that keep an empty box on site.
- **Separate heavy material.** Keep concrete, block and masonry in a dedicated small box filled partway, so the general debris box is not pushed overweight.
- **Keep the site clear.** A box on site means crews are not stockpiling debris; swaps keep it flowing on a longer job.
- **Mind Lee County's C and D recycling** requirement, which a local hauler routes accordingly.

Describe the project scope, pace and debris mix to the hauler so they size the box and plan any swaps.
